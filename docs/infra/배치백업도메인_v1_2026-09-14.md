## 2. 도메인 (#46)

### 2.1 사용자 선택과 대가

권장안은 "개발 중 무료, 공개 직전 구매"였다. 사용자는 "사용자가 늘면 구매"를 골랐다. 연 1~2만 원 고정 비용을 트래픽이 확인될 때까지 미룬다는 판단이다.

| 대가 | 보완 |
|---|---|
| **엣지 방어 없음.** WAF 속도 제한 규칙·Bot Fight Mode·AI 크롤러 차단은 존(도메인)에 걸린다. `workers.dev`는 존이 아니다 | Rate Limiting 바인딩(Worker 안에서 동작, #23), 가입 Turnstile, 유저 쿼터, 차단 스위치, 9GB 차단. **Workers 무료 플랜이라 폭주해도 과금이 아니라 장애**(#20 원칙 2). R2만 예외 — 쓰기는 로그인 필수라 익명 폭주로 R2가 늘지 않는다 |
| 도메인을 옮기는 날 **유튜브 설명란 링크·외부 링크·색인**이 옛 주소를 가리킨다 | 옛 `workers.dev` Worker를 **301 리다이렉트 전용**으로 남긴다. 경로를 그대로 새 도메인으로 넘긴다 |
| 소셜 로그인(카카오·네이버·구글) 콜백 URL, 개인정보 처리방침 URL을 다시 등록 | 이전 체크리스트(2.3)로 관리 |
| 원하는 이름이 선점될 수 있다(인프라확장플랜 7장) | 감수. 이름 후보를 미리 적어두고 주기적으로 확인 |
| 구글 로그인 동의 화면을 "프로덕션"으로 올릴 때 도메인 소유 확인이 필요할 수 있다 | **미확인.** M2에서 확인. 막히면 그 시점이 구매 트리거 |

### 2.2 구매 트리거

사용자 표현은 "사용자가 늘기 시작하면". 판정을 미루지 않게 **아래 중 먼저 오는 것**을 트리거로 제안한다 `[초안]`.

- 운영자 외 작성자가 처음 작례를 올림 (#43 판정 대상의 첫 1명)
- 유튜브 채널을 열어 영상 설명란에 사이트 링크를 걸기 직전
- `daily_metrics`의 429 발생·요청 수가 공격 징후를 보임 — 엣지 방어가 필요해진 때
- 구글 로그인 등 외부 서비스가 커스텀 도메인을 요구할 때 (2.1)

### 2.3 도메인 없이 지키는 규칙

- **DB와 글 본문에 `https://…workers.dev/…` 같은 절대 URL을 저장하지 않는다.** 사이트 내부 링크는 경로(`/kit/...`)로, 이미지는 `storage_key`로 저장하고 출력 시 설정값의 도메인을 붙인다
- 도메인·이미지 도메인은 `platform/env.ts`의 설정값 한 곳에서만 읽는다
- `robots` noindex는 도메인과 무관하게 공개 조건(#12)을 따른다
- 이미지 서빙은 `workers.dev`에서도 캐시가 적용되는지 **구현 시 확인**. 안 되면 R2 공개 버킷 주소(`r2.dev`)의 속도 제한·캐시 조건을 확인한다

### 2.4 도메인 구매 시 이전 체크리스트

- [ ] Cloudflare에 존 추가, Worker 커스텀 도메인 연결
- [ ] 옛 `workers.dev`는 301 리다이렉트 전용 Worker로 교체 (본 서비스는 `workers_dev: false`)
- [ ] 카카오·네이버·구글 콜백 URL, 허용 도메인 갱신
- [ ] 개인정보 처리방침·약관 URL 갱신, 카카오 비즈 앱 정보 갱신
- [ ] Bot Fight Mode, AI 크롤러 차단, WAF 속도 제한 규칙 켬 (비용 어뷰징 방어 5장 "배포 시작 시")
- [ ] 검색엔진 도구에 새 도메인 등록 (공개 후라면 주소 변경 신고)
- [ ] 유튜브 설명란 링크는 리다이렉트로 유지되는지 확인

## 3. 배치 — GitHub Actions (#47)

### 3.1 왜

| 후보 | 판단 |
|---|---|
| **GitHub Actions** | 채택. 레포가 공개라 표준 러너 무료·무제한. `pg_dump`·`astro build` 실행 가능. 임시 Postgres(서비스 컨테이너)로 복구 훈련 자동화 가능 |
| Cloudflare Workers Builds | 푸시 시점 빌드용. 스케줄 실행·`pg_dump` 바이너리 불가 |
| Worker Cron Trigger | Worker 런타임 안이라 `pg_dump`·빌드 불가. CPU 제한 |

### 3.2 작업 목록

| 작업 | 주기 | 비고 |
|---|---|---|
| 킷·기체 SSG 빌드 + 배포 | 매일 | DB 직접 연결로 읽기(Hyperdrive 아님) |
| DB 백업 → Google Drive | 매일 | 4장 |
| 고아 이미지 정리 | 매일 | #25. R2는 S3 호환 API로 |
| Web Analytics 스냅샷 → `daily_metrics` | 매일 | #39 |
| 복구 훈련 | 매주 | 4.3 |
| 백업 신선도 확인 | 매주 (복구 훈련에 포함) | 최신 백업이 26시간 이내인지 |

### 3.3 공개 레포라서 지킬 것

- **워크플로 로그는 누구나 본다.** 연결 문자열·토큰은 GitHub Secrets로만 넣고, 명령에 인자로 넘기지 않는다
- 로그에 **DB 행 내용, 테이블별 행 수를 출력하지 않는다.** 복구 훈련 결과는 통과/실패만 출력한다(행 수는 가입자 수 같은 지표를 드러낸다)
- 백업 파일을 Actions 산출물(artifact)로 올리지 않는다. 공개 레포 산출물은 외부에서 받을 수 있다
- 포크에서 실행되는 PR 워크플로가 Secrets에 닿지 않게 한다 (스케줄·수동 실행만 Secrets 사용)

### 3.4 옮기려면 (#19)

워크플로는 레포의 YAML이고 실제 작업은 `scripts/`의 셸·Node 스크립트로 둔다. 다른 CI(GitLab CI, 자체 서버 cron)로 옮길 때 YAML만 다시 쓴다. GitHub가 막히면 레포 사본으로 어디서든 실행한다.

## 4. DB 백업 — Google Drive (#48)

### 4.1 선택과 대가

권장안은 Backblaze B2(S3 호환, 제3 벤더)였다. 사용자는 이미 쓰는 Google Drive를 골랐다.

| 조건 (#19) | Google Drive |
|---|---|
| DB 벤더(Neon) 밖 | 충족 |
| 앱 벤더(Cloudflare)와도 분리 | 충족 |
| 자동화 | rclone으로 가능. S3 호환은 아님 |
| 용량 | 무료 15GB(Gmail·사진과 공유). 초기 덤프는 수 MB |

**걸리는 점 — 인증이 조용히 만료될 수 있다.** rclone이 쓰는 Google OAuth 앱을 "테스트" 게시 상태로 두면 갱신 토큰이 7일 뒤 만료되는 것으로 알려져 있다(**구현 시 확인**). 그러면 백업 업로드가 실패한 채로 지나간다.
- 대응 1 — 자체 OAuth 클라이언트를 만들고 "프로덕션" 상태로 둔다(본인만 쓰는 미인증 앱)
- 대응 2 — **주 1회 복구 훈련이 Drive에서 최신 백업을 내려받아 26시간 이내인지 확인**한다. 만료돼도 최대 1주 안에 알림이 온다
- 서비스 계정은 개인 Drive에 저장 용량이 없어 쓰지 않는다(**구현 시 확인**)

### 4.2 형식과 보관

| 항목 | 규칙 |
|---|---|
| 형식 | `pg_dump --format=custom` → **암호화**(age) → 업로드. 개인정보(이메일, 연결 계정)가 들어 있다 |
| 키 | 복호화 키는 GitHub Secret(복구 훈련용) + **오프라인 사본 1개**(사용자 보관). Drive에 두지 않는다 |
| 경로 | `G-MOIM-backup/daily/`, `G-MOIM-backup/monthly/` |
| 보존 | daily 14개, monthly 12개(매월 1일 백업을 복사). 오래된 것은 배치가 지운다. Drive에는 수명 규칙이 없다 |
| 함께 저장 | 백업 시점의 테이블별 행 수(암호화 파일 안에). 복구 훈련 대조 기준 |

### 4.3 복구 훈련 (주 1회)

```
1. Drive에서 최신 daily 백업 다운로드 → 26시간 넘었으면 실패
2. 복호화
3. Actions 서비스 컨테이너의 빈 Postgres(운영과 같은 메이저 버전)에 pg_restore
4. 테이블별 행 수를 백업 시점 기록과 대조
5. 로그에는 통과/실패만. 실패 시 알림
```

- 알림 수단은 GitHub Actions 실패 메일로 시작한다(추가 벤더 없음)
- 연 1회는 사람이 직접 **다른 호스팅 Postgres**(예: 다른 무료 벤더)에 복구해본다. 컨테이너 복구만으로는 "Neon이 막힌 날 어디로 옮기나"를 연습하지 못한다

### 4.4 옮기려면 (#19)

rclone 설정만 바꾸면 B2·S3·R2 등으로 옮긴다. 기존 백업은 `rclone copy`로 새 저장소에 복사한다.
