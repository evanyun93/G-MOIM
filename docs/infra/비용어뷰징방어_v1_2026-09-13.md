# 비용 어뷰징 방어 v1

악의적 사용자나 봇이 트래픽·업로드·연산을 유발해 **요금 폭탄**을 만들거나 서비스를 마비시키지 못하게 하는 설계 기준. 결정 #20.

작성 2026-09-13 · 벤더 정보 확인 2026-09-13

> **주의** — 벤더 한도·가격·보호 기능은 자주 바뀐다. 구현 전에 공식 문서를 재확인할 것.

---

## 1. 원칙

1. **지출 상한은 벤더가 대신 걸어주지 않는다.** Cloudflare 유료 플랜에는 자동 지출 상한이 없다. 예산 알림은 통지 전용이고 **다음 날** 온다. 상한은 우리가 설계로 건다
2. **무료 플랜은 자연 상한이다.** 한도를 넘으면 에러가 날 뿐 과금되지 않는다. 공격의 결과가 "청구서"가 아니라 "일시 장애"가 되도록 한다. 유료 전환은 트래픽이 지표로 확인됐을 때만(인프라확장플랜 트리거)
3. **돈이 드는 동작은 전부 누가 몇 번 했는지 센다.** 익명 사용자가 비용을 유발하는 경로를 최소화한다
4. **비싼 동작일수록 앞단에서 거른다.** 순서: 정적 파일 → CDN 캐시 → WAF/봇 차단 → 앱 레벨 제한 → 실제 연산
5. **끄는 스위치를 먼저 만든다.** 공격이 오면 비용 드는 기능을 1분 안에 끌 수 있어야 한다
6. **플랫폼 방어 기능은 이식성 원칙(#19)을 따른다.** Cloudflare 전용 기능(속도 제한 바인딩 등)은 어댑터 모듈 한 곳에서만 쓴다

## 2. 비용 벡터별 위협과 방어

| # | 비용 벡터 | 공격 방식 | 무료 플랜에서 결과 | 유료 플랜에서 결과 | 방어 |
|---|---|---|---|---|---|
| 1 | **Workers 요청** (작례 SSR, API) | 요청 폭주 | 일 10만 초과 → 장애 | 100만당 $0.30 | WAF 속도 제한, 봇 차단, 캐시 적중률 유지 |
| 2 | **Workers CPU** | 쿼리스트링을 바꿔 캐시를 우회, 매번 렌더 유발 | 요청당 10ms 초과 → 에러 | CPU ms 과금 | 캐시 키에서 불필요한 쿼리스트링 제거, 알 수 없는 파라미터 거부, `limits.cpu_ms` 설정 |
| 3 | **R2 쓰기 (Class A)** | 업로드 스팸, 대량 가입 후 업로드 | 월 100만 초과분 **과금** | 100만당 $4.50 | 로그인 필수, 유저별 일일 업로드 수·용량 쿼터, 크기 제한, 신규 계정 제한 |
| 4 | **R2 저장 용량** | 대용량 파일 반복 업로드 | 10GB 초과분 **과금** | GB당 과금 | 업로드 전 크기 검증, 변환 후 저장(원본 미보관), 유저별 총 용량 한도, **전체 저장량 9GB 자동 차단**(#33) |
| 5 | **R2 읽기 (Class B)** | 캐시 우회 쿼리로 이미지 반복 요청, 핫링크 | 월 1000만 초과분 **과금** | 100만당 $0.36 | 이미지는 CDN 캐시 경유(Worker 미경유), 이미지 도메인은 쿼리스트링 무시, 핫링크 차단 |
| 6 | **DB 연산** (Neon) | 무거운 검색 쿼리 반복, 페이지네이션 끝까지 긁기 | CU-hour 소진 → 정지 | 오토스케일링 과금 | `statement_timeout`, 검색어 최소 길이, 결과 수 상한, 검색 API 속도 제한, 최대 CU 고정 |
| 7 | **메일 발송** (가입 인증, 비밀번호 재설정) | 남의 주소로 대량 발송 | 발송 한도 소진, 도메인 평판 하락 | 건당 과금 | **MVP에서 제거** — 소셜 전용 로그인이라 인증·재설정 메일이 없다(#29). 메일 기능을 추가할 때 Turnstile, 주소별·IP별 발송 간격, 일일 발송 상한 |
| 8 | **계정 대량 생성** | 봇 가입 → 3·4번 증폭 | 위 항목 연쇄 | 위 항목 연쇄 | 소셜 인증 필수(#29), 가입 단계 Turnstile, 신규 계정 신뢰 단계 |
| 9 | **LLM 호출** (향후 모더레이션) | 신고 남발, 긴 글 대량 게시 | — | 토큰 과금 | 신고·필터 통과분만 호출, 유저별 신고 한도, 전역 일일 예산 차단기 |
| 10 | **빌드 분** | 재빌드 트리거 남용 | 월 3,000분 소진 | 분당 과금 | 공개 재빌드 트리거를 만들지 않는다. 스케줄 배치만 |
| 11 | **workers.dev 우회** | 커스텀 도메인의 WAF를 피해 `*.workers.dev`로 직접 요청 | 위 항목 전부 | 위 항목 전부 | **운영 Worker는 `workers_dev: false`.** 커스텀 도메인으로만 노출. **도메인 구매 전까지 유예(#46)** — 앱 레벨 방어(Rate Limiting 바인딩·Turnstile·쿼터·스위치)로 버틴다 |

## 3. 계층별 방어 장치

### 3.1 엣지 (Cloudflare 존 설정)

- **커스텀 도메인 필수.** WAF, 봇 차단, 속도 제한은 존(도메인)에 걸린다. `workers.dev`와 프리뷰 URL은 운영에서 끈다
  - **#46으로 유예** — 도메인 구매 전까지 `workers.dev`로 운영하며 이 절의 엣지 장치는 없다. 구매 트리거·이전 절차는 `docs/infra/배치백업도메인_v1` 2장
- **Bot Fight Mode** 켬 (무료)
- **AI 크롤러 차단** 켬, `robots.txt` 정비
- **WAF 속도 제한 규칙** — 무료는 1개(IP 기준, 10초 단위). 가장 비싼 경로 하나에 쓴다: 업로드·쓰기 API 경로 묶음
- **캐시 규칙** — 이미지 도메인은 쿼리스트링 무시, 긴 TTL
- **핫링크 차단** — 이미지 도메인에 Referer 검사

### 3.2 앱 레벨 (코드)

- **모든 쓰기 API는 인증 필수.** 익명 쓰기 엔드포인트를 만들지 않는다
- **Turnstile** — 신규 가입(소셜 로그인 후 계정 생성), 신고. 비밀번호·재설정 흐름은 MVP에 없다(#29)
- **유저별 쿼터 테이블** — 일일 업로드 수, 일일 업로드 용량, 총 저장 용량, 일일 글 수, 일일 신고 수. 초과 시 429
- **신규 계정 신뢰 단계** — 가입 직후는 낮은 쿼터. 가입 경과일, 정상 활동, 연결한 소셜 수에 따라 상향 (설계 문서 부록 A의 신뢰도와 연결)
- **입력 검증을 비용 발생 전에** — 업로드는 Worker를 거치며 크기·타입을 먼저 검사하고 R2에 쓰기 전에 거부. 변환은 브라우저가 하므로(결정 #26) 서버는 결과를 믿지 않고 헤더로 재검증한다. 검증을 우회하는 R2 직접 서명 URL은 만들지 않는다
- **캐시 키 정규화** — SSR 페이지는 허용된 쿼리 파라미터만 캐시 키에 반영. 나머지는 무시하거나 거부
- **DB 보호** — 커넥션별 `statement_timeout`, 모든 목록 쿼리에 `LIMIT`, 커서 기반 페이지네이션, 검색어 최소 2자 이상 + 속도 제한

### 3.3 플랫폼 설정 (레포의 `wrangler.jsonc` 등)

- `limits.cpu_ms` 설정 — 요청 하나가 쓸 수 있는 CPU 상한
- `workers_dev: false`, 프리뷰 URL 비활성
- Neon — 최대 CU 고정, 소비 한도(consumption limit) 설정 (유료 전환 시)
- 설정은 전부 레포에 둔다(#19). 대시보드에서만 존재하는 방어 설정을 만들지 않는다. 대시보드에서만 가능한 것(Bot Fight Mode 등)은 이 문서 5장 체크리스트로 관리

### 3.4 관측과 알림

- **Cloudflare 예산 알림** — 유료 전환 즉시 낮게 설정 (예: $10, $30). 다음 날 오는 통지라 1차 방어가 아니다
- **자체 일일 지표** — `daily_metrics`에 요청 수, 업로드 수·용량, 신규 가입 수, 429 발생 수를 적재. 전일 대비 급증 시 알림
- **Cloudflare Analytics** — 캐시 적중률 85% 미만이면 캐시 우회 공격 또는 설정 오류 의심

## 4. 차단 스위치 (Kill Switch)

공격 중에는 원인 분석보다 **비용 차단이 먼저**다.

| 스위치 | 효과 | 전환 방법 |
|---|---|---|
| `UPLOADS_ENABLED=false` | 이미지 업로드 전면 중지 | 환경 변수 변경 후 재배포 |
| `SIGNUP_ENABLED=false` | 신규 가입 중지 | 동일 |
| `READ_ONLY=true` | 모든 쓰기 중지, 조회만 | 동일 |
| `SEARCH_ENABLED=false` | 검색 API 중지 | 동일 |
| WAF "Under Attack" 모드 | 전 방문자 챌린지 | Cloudflare 대시보드 |

- 스위치는 코드 초기부터 넣는다. 공격받고 나서 만들면 늦다
- 전환 절차는 공개 전에 한 번 실제로 해본다

### 공격 대응 순서

1. 비용이 도는 기능을 스위치로 끈다
2. Under Attack 모드 또는 WAF 규칙으로 트래픽을 걸러낸다
3. 로그로 공격 경로를 특정한다
4. 해당 경로에 영구 방어(쿼터, 규칙)를 추가하고 이 문서 2장에 행을 추가한다
5. 스위치를 되돌린다
6. 개발일지에 기록한다

## 5. 구현 체크리스트

기능을 만들 때 해당 항목을 확인한다. **공개(홍보) 전에는 전 항목 완료.**

### 배포 시작 시

- [ ] 커스텀 도메인 연결, `workers_dev: false` — 도메인 구매 전까지 유예(#46). 대신 Rate Limiting 바인딩이 `workers.dev` 요청에도 걸리는지 확인
- [ ] Bot Fight Mode, AI 크롤러 차단 켬
- [ ] `limits.cpu_ms` 설정
- [ ] 차단 스위치 환경 변수 4종 동작 확인

### 계정 기능 구현 시

- [ ] 신규 가입 단계에 Turnstile
- [ ] 소셜 인증 없이 계정이 생기는 경로가 없는지 확인 (#29)
- [ ] 캐시된 작례 HTML에 로그인 상태가 섞이지 않는지 — 로그인 A로 조회 후 비로그인 B로 같은 URL 조회해 대조 (#30)
- [ ] (메일 기능 추가 시) 발송 주소별·IP별 제한

### 업로드 구현 시

- [ ] 인증 필수
- [ ] 크기·타입 검증이 R2 쓰기보다 앞
- [ ] 서버 헤더 검증: 매직 바이트로 실제 포맷 확인, 장변 2048px 이하, EXIF/XMP 청크 없음, 용량 상한 (#26)
- [ ] 변조한 클라이언트로 원본(EXIF 포함, 고해상도)을 직접 보냈을 때 거부되는지 테스트
- [ ] 유저별 일일 수·용량, 총 용량 쿼터 (초기값: 아키텍처 4.5)
- [ ] 전체 저장량 9GB 도달 시 업로드 자동 중지 — 합계를 임계치 근처로 조작해 실제 거부되는지 테스트 (#33)
- [ ] 변형본 크기 상한(2048: 3MB · 1024: 800KB · 400: 150KB) 초과 거부
- [ ] 본문 JSON의 이미지 노드에 **남의 `image_id`**를 넣어 저장했을 때 거부되는지 테스트 (#31)
- [ ] 유튜브 노드에 ID 대신 임의 URL·다른 도메인·추가 속성을 넣어 저장했을 때 렌더에서 버려지는지 테스트 (#36)
- [ ] WAF 속도 제한 규칙을 업로드 경로에
- [ ] 운영자 역할을 API로 스스로 부여할 수 없는지, 운영자도 9GB 차단에 걸리는지 (#44)
- [ ] 이관 스크립트가 일반 업로드 API를 거치는지 — 검증 실패 파일이 이관 경로로 저장되지 않는지 (#45)

### 댓글 구현 시

- [ ] 로그인 필수, 쓰기 가드 체인 통과 (#38)
- [ ] 유저별 일일 댓글 수 쿼터, 신규 계정 낮게
- [ ] 댓글 본문 길이 상한, HTML·마크다운 렌더 없음
- [ ] `draft`·`private` 글에 댓글 API로 쓸 수 없는지
- [ ] 댓글 작성·삭제 시 해당 글 캐시만 무효화되는지 (전체 무효화로 캐시 적중률이 떨어지지 않게)
