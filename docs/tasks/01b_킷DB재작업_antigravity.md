## 3. MG 목록 절차

### 3.1 뼈대는 공식 소스 하나로 만든다

**제조사 공식 MG 라인업(`bandai-hobby.net`)을 뼈대로 삼는다.** 이전 notes에 "총 57쪽"으로 접근 기록이 있다.

- 공식 목록의 항목을 전부 옮긴다. 공식에 없는 것은 3.3에서 따로 더한다
- 여러 소스를 동시에 섞어 넣지 않는다. 이전 결과물이 표기가 뒤섞인 원인이다

### 3.2 목록 형식 — 01a 5.2를 대체

```markdown
| # | name_ja | 발매연월 | 유통 | 판매 | 출처 | 비고 |
|---|---|---|---|---|---|---|
| 1 | MG 1/100 RX-78-2 ガンダム | 1995-07 | 일반 | 판매 | bandai-hobby.net | |
```

| 칸 | 규칙 |
|---|---|
| `name_ja` | **공식 제품명 그대로.** 이것이 중복 판정 기준 표기다. 01_v2 7.1(전각 하이픈, 가타카나 대체 금지) 적용 |
| 발매연월 | `YYYY-MM`. 월 미상이면 `YYYY-??` |
| 유통 | `일반` `프리미엄반다이` `건담베이스` `이벤트` `미확인` 중 하나. **다른 값 금지** |
| 판매 | `판매` 또는 `비매품`. 캠페인 경품·당첨 선물·증정품은 `비매품` |
| 출처 | 도메인 |
| 비고 | **짧은 사실 태그만.** 예: `재판`, `3.3에서 추가`, `소스 충돌`. 문장 금지 |

**제품명 칸에는 제품명만 넣는다.** 괄호 안의 발매 연월, 판매 경위, "以上2点" 같은 서술은 소스에 붙어 있어도 떼어낸다. 판매 경위가 필요하면 `유통`과 `판매` 값으로만 표현한다. 이 규칙을 어긴 행이 하나라도 있으면 반려한다.

한국어 제품명은 이 단계에서 넣지 않는다. CSV 단계에서 채운다.

### 3.3 공식 소스에 없는 것을 더한다

공식 라인업은 프리미엄반다이·이벤트 한정을 빠뜨리는 경우가 있다. 두 번째 소스로 보완한다.

- 보완 소스 후보 — 프리미엄반다이 상품 페이지, ja.wikipedia.org 마스터그레이드 항목(**제품명·연월만. 서술 금지**)
- 추가하는 행은 `비고`에 `3.3에서 추가`, 출처에 해당 도메인
- 추가 행도 `name_ja`는 공식 표기로 쓴다. 공식 표기를 찾지 못하면 소스 표기를 쓰고 `비고`에 `표기 미확인`

### 3.4 대조 — 빠진 것과 겹친 것

1. **중복** — `name_ja`가 같거나, 같은 제품의 표기 차이(공백, 기호, `Ver.` 표기)인 행을 찾는다. 합친 내역을 notes에 표로 남긴다
2. **누락 대조** — `_rejected_2026-09-13/MG/coverage_checklist.md`의 627종과 비교해, **옛 목록에 있는데 새 목록에 없는 항목**을 전부 notes에 적는다. 각각 `추가함` / `비매품이라 판매=비매품으로 추가함` / `실존 확인 안 됨` / `MG 아님(MGEX·MGSD 등)` 중 하나로 처리 결과를 단다

### 3.5 연도별 커버리지 표

01a 5.3 형식을 그대로 쓴다. 단 두 가지를 더 지킨다.

- **근거 칸을 연도마다 실제로 쓴다.** 모든 행에 같은 문구를 복사하면 확인하지 않은 것으로 본다
- 2018~2026년 **일반** 칸은 공식 라인업과 **다른 소스 1곳**의 건수를 둘 다 적는다. 예: `공식 8 / 유통사A 8`. 두 수가 다르면 차이 나는 제품명을 notes에 적는다

비매품은 연도별 건수에서 **빼고** 따로 합계만 적는다.
