**전제 정정 (2026-09-13 확인)**

- "Pages 빌드 월 500회"는 Pages Git 연동에만 해당해 병목이 아니다
- 정적 에셋 요청은 무료·무제한이고 Worker를 호출하지 않는다. 대신 배포당 정적 파일 2만 개(무료) 한도가 있어 작례를 SSG로 만들 수 없다
- **Workers Cache 적중은 Worker 코드를 실행하지 않지만 요청 수로는 과금·한도 차감된다.** 작례 조회는 일 10만 한도를 소모한다. 이를 알고 A안(SSR+캐시)을 택했다
