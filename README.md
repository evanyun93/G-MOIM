# G-MOIM

건담 프라모델 커뮤니티 플랫폼. 개인 프로젝트.

킷 위키(공용) + 개인 작례 아카이브 + 커뮤니티를 한 사이트에 결합한다.
기존 플랫폼은 실시간 소통과 개인 아카이브 중 하나만 갖고 있고,
구조상 나머지 하나를 붙일 수 없다는 것이 출발점이다.

## 저장소 구조

| 경로 | 내용 |
|---|---|
| `docs/design/` | 설계 문서. v 번호가 가장 큰 파일이 최신 |
| `docs/architecture/` | 인프라 구성도, 요청 흐름, 코드 계층 그림 |
| `docs/journal/` | 개발 일지. 판단이 갈릴 때만 기록 |
| `docs/infra/` | 인프라 확장 플랜, 벤더 선택지 |
| `docs/tasks/` | 외부 AI 세션에 위임하는 작업의 지시서 |
| `data/kits/` | 킷 카탈로그 데이터 |
| `data/aliases/` | 검색·자동매칭용 별칭 사전 |

## 문서 규칙

- 설계 문서는 덮어쓰지 않고 버전 파일을 쌓는다. 뒤집힌 이력 자체가 기록물이다
- 버전을 올리는 기준은 결정 5건 이상 누적 또는 구조 변경
- 개발 일지는 날짜별. 판단이 갈렸을 때만 쓰고 한 건 5분을 넘기지 않는다
- 일지 각 항목의 "미판정 질문"에 나중에 `→ 판정:`을 이어 붙인다

## 브랜치

| 브랜치 | 용도 |
|---|---|
| `main` | 검증 완료된 것만 |
| `data/kit-db` | 킷 카탈로그 수집 작업. 검증 후 main으로 머지 |

## 현재 상태

설계 단계. 확정 결정 34건, 설계 문서 v3. 기술 스택 선정 완료(Astro · Cloudflare Workers · Neon · Drizzle · Tailwind), 인증은 Better Auth 소셜 전용. 상세는 `docs/STATUS.md`.
MVP 범위는 킷 위키 + 개인 블로그 + 계정. 커뮤니티 게시판은 제외.
